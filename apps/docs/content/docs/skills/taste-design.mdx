---
title: Taste Design
description: Build intentional Vayu UI layouts with restrained typography and useful visual hierarchy.
---

Install the skill through [skills.sh](https://skills.sh/docs):

```bash
npx skills add Rugved1652/vayu-ui --skill taste-design
```

The skill helps agents preserve your product's visual direction, use `Typography` instead of custom heading wrappers, keep application headings proportionate, and avoid unnecessary gradients, oversized titles, repeated cards, and decorative icons.

It also asks agents to inspect narrow layouts, long content, focus states, loading, and errors. An explicitly requested marketing hero can still have distinctive display typography.

`vayu-ui create` includes this skill in the generated project. Canonical skill sources live in the repository's `skills/` directory and are copied into the CLI package during its build.
